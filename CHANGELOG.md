# Changelog

### 1.3.0
- Update native modules to use [Voximplant Android Kit Chat UI SDK 1.5.0](https://voximplant.com/kit/docs/references/android/kitchatui/changelog) and [Voximplant iOS Kit Chat UI SDK 1.7.0](https://voximplant.com/kit/docs/references/ios/sdk_ui/changelog)
- Introduce the `KitRegion.MX` API
- Important: Update the minimum supported React Native version to 0.77

### 1.2.0
- Update native modules to use Voximplant Android Kit Chat UI SDK 1.0.3
- Important: Rolling back to a previous version on Android is not supported due to database changes.

### 1.1.0
- Update native modules to use Voximplant Android Kit Chat UI SDK 1.0.2 and Voximplant iOS Kit Chat UI SDK 1.5.0
- Introduce the `KitColorScheme.avatarPlaceholder` API to customize the avatar placeholder color.

### 1.0.0
- Initial release
